# ManaApp

Программа-помощник стримера для Windows с игрой «Пробуждение Дракона».

Здесь публикуются **готовые сборки**: исходный код в этом репозитории не хранится.

## Как установить

1. Откройте [последний релиз](https://github.com/zeroyuranchik-stack/ManaApp/releases/latest).
2. Скачайте `ManaApp-vX.Y.Z-windows-x64.zip`.
3. Распакуйте в любую папку и запустите `ManaApp.exe`.

При первом запуске откроется мастер настройки. Настройки и данные хранятся рядом
с программой в папках `configs`, `data`, `logs`.

## Обновления

Программа сама проверяет новые версии в этом репозитории: при старте и раз в сутки,
во время эфира — нет. Установить обновление: «Модули → Кор → Проверка» → «Установить».
Архив проверяется по SHA-256, настройки и данные сохраняются.

Проверить архив вручную:

```powershell
Get-FileHash .\ManaApp-vX.Y.Z-windows-x64.zip -Algorithm SHA256
```

Хэш должен совпасть со строкой `SHA-256` в описании релиза и с файлом `.sha256`.
